# YL_ML_seminar_5_practice

Решённая практика пятого семинара Яндекс Лицея: введение в нейронные сети и PyTorch.

## Содержание

В ноутбуке разобраны тензоры, автоматическое дифференцирование, датасеты и загрузчики данных, построение и обучение нейросети. Используются синтетическая выборка `make_moons` и примеры с MNIST.

## Запуск

```sh
python -m pip install jupyterlab torch torchvision numpy matplotlib scikit-learn
jupyter lab ml_practice_5_intro_to_deep_learning_solved.ipynb
```

Выполняйте ячейки последовательно. Для загрузки MNIST потребуется интернет; для базовых упражнений достаточно CPU. Зависимости устанавливайте в отдельное виртуальное окружение.
